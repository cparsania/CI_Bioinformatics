📝 Practice Questions

📏 1. Vectors and Basic Operations

  1. Create a numeric vector of numbers from 1 to 10.
  2. Multiply each element of the vector by 3.
  3. Create a character vector of your favorite 5 fruits.
  4. Create a logical vector indicating whether elements of 1:10 are even.

📦 2. Lists and Matrices

  1. Create a list containing your name, age, and a numeric vector of scores.
  2. Access the second score from the list.
  3. Create a 3x4 matrix of numbers from 1 to 12.
  4. Extract the element in the 3rd row and 2nd column of the matrix.

📁 3. Data Frames and Factors

  1. Create a data frame with columns: Name, Age, and Gender (as factor) for 4 people.
  2. Add a column “Score” with random numbers between 60 and 100.
  3. Filter the data frame to show only rows where Score > 80.

🔍 4. Subsetting

  1. From the data frame above, extract the “Name” and “Score” columns.
  2. Select the first 2 rows of the data frame.
  3. From a list of numbers, extract all values greater than 10.

🔁 5. Loops and Conditionals

  1. Use a for loop to print numbers from 1 to 5.
  2. Use a while loop to print numbers from 10 down to 6.
  3. Use an if-else to print “Pass” if score > 60, otherwise “Fail”.

🛠️ 6. Functions

  1. Write a function that takes a vector and returns its mean.
  2. Write a function that checks whether a number is prime.
  3. Write a function that counts how many numbers in a vector are greater than the mean.

6. Functions

mean_func <- function(x) {
  mean(x)
}

is_prime <- function(n) {
  if (n < 2) return(FALSE)
  for (i in 2:sqrt(n)) {
    if (n %% i == 0) return(FALSE)
  }
  return(TRUE)
}

greater_than_mean <- function(x) {
  sum(x > mean(x))
}
